# Known limits

- **Provider-defined reviews and actions:** custom review/action metadata comes from native service schemas; data-only integration files cannot declare it. Lines can still add a generic `gate:review`. Sources: `backend/app/services/operator_dispatch.py:119-120`, `backend/app/services/integration_operations.py:1474`, `backend/app/services/line_engine.py:401`.
- **Declarative upgrades:** changed contents or a new version for an existing file import return HTTP 409; there is no file-definition upgrade path yet. Sources: `backend/app/services/integration_file.py:338-351`, `backend/app/routers/integration_management.py:335-337`.
- **Swagger:** the helper refuses Swagger 2.0; convert it to OpenAPI 3.x. Source: `backend/app/services/integration_drafts.py:421-422`.
- **Source URLs:** the helper refuses embedded credentials, query strings, fragments, and traversal; download the spec and paste it or host it at a clean URL. Source: `backend/app/services/integration_drafts.py:544-549`.
- **Sensitive schema names:** properties named `token`, `password`, or similar can trip the secret guard even when they are only remote schema fields. Sources: `backend/app/services/integration_file.py:40`, `163-187`.
- **CLI helper drafts:** GitHub-discovered command drafts cannot be probed or enabled in Lynewright; deploy and test the wrapper separately, then import its OpenAPI declaration. Sources: `backend/app/services/integration_drafts.py:150`, `188`.
- **Async declarations:** the declarative `async` block is OpenAPI-only. Native providers can implement declared async operations; MCP and webhook files cannot define polling. Sources: `backend/app/services/integration_file.py:208-212`, `backend/app/services/integration_operations.py:818-835`.
- **MCP uploads:** MCP operations reject `lynewright-upload`; use a `lynewright-media` link or another operation kind that accepts uploads. Source: `backend/app/services/integration_operations.py:159-161`.
- **Webhook lines and tests:** webhooks do not declare callable operations, and `lynewright-testkit` has no signed-webhook sender helper. Sources: `backend/app/services/integration_file.py:234-235`, `testkit/README.md:18-21`.
- **Windows wrapper checks:** the CLI starter skips POSIX process-tree and symlink checks on Windows. Sources: `../../templates/starters/cli-wrapper/tests/test_wrapper_security.py:134`, `144`, `157`.
- **Container catalogue entries:** an entry needs a published immutable image digest. GHCR publication is a K6 decision, so the thumbnail remains a draft and is absent from signed releases. Sources: `../../catalogue/entries/lynewright.integration.template-thumbnail/1.0.0.yaml:3-4`, `../../catalogue/README.md:17`, `23`.
- **Runner egress:** runner policy supports `none` or `internet`; a per-host egress allowlist is not implemented. Sources: `backend/app/services/runner_runtime_config.py:73-75`, `163`.
- **In-process execution:** packages run in the API only with `LYNEWRIGHT_ALLOW_INPROCESS_PACKAGES=1`; Integrations marks that execution with a critical red badge. Sources: `backend/app/services/integration_definition_compiler.py:176`, `frontend/src/components/integrations/IntegrationExecutionBadge.tsx:16`.
- **Runner dependencies:** the base image installs all backend requirements and integration wheels install with `--no-deps`; vendor other dependencies or add them to the runner base. Sources: `runner/Containerfile:8-10`, `runner/Containerfile.integration:12`.
